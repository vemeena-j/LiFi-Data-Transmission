## 📌 Project Overview

Li-Fi (Light Fidelity) is a wireless communication technology that uses light to transmit data.

This project is a software-based Li-Fi data transmission simulator. It demonstrates how text data can be converted into binary data, transmitted through a virtual LED using ON/OFF light states, and converted back into the original message.

## ⚙️ How It Works

Text Message  
→ Binary Conversion  
→ Virtual LED Transmission  
→ Binary Reception  
→ Text Reconstruction

## 🚀 Features

- Enter any text message
- Convert text into 8-bit binary
- Simulate LED ON/OFF transmission
- Display transmission progress
- Reconstruct the received message
- Verify successful data transmission
